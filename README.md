# Semiconductor Market Risk & Prediction Engine via Knowledge Graphs

## Final Year Project

A knowledge-graph-driven system for modeling semiconductor supply-chain dependencies, detecting market and geopolitical events, and propagating risk through multi-hop supply-chain relationships.

## Core Technologies

- Neo4j
- Python
- FastAPI
- NLP
- Graph Data Science
- Knowledge Graphs
- Event-Driven Architecture
